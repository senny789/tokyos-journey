# TJ-06 · Senny throws the toy to start the journey

**Status** — Proposed

After Tokyo brings a toy to Senny, Senny throws it. Chasing the toy starts Tokyo's journey.

## Acceptance criteria

- [ ] Senny throws the toy Tokyo brought, and the player can see where it goes.
- [ ] The game cues the player to send Tokyo after the toy.
- [ ] Following the toy takes Tokyo into the first journey section.
