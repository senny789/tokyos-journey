# TJ-13 · Let treats increase stamina

**Status** — Proposed

Eating a treat increases Tokyo's current stamina by an amount set for that treat.

## Acceptance criteria

- [ ] Eating a treat below maximum stamina increases Tokyo's current stamina and updates the display.
- [ ] Each treat uses its configured stamina amount, and the result stays within Tokyo's current maximum.
- [ ] A single treat applies its stamina gain once. Reshu's treats follow the same rule when available. [TJ-04 · Reshu gives Tokyo treats](TJ-04-reshu-gives-treats.md)

## Depends on

- [TJ-12 · Increase Tokyo's level and stamina](TJ-12-level-and-stamina-progression.md)

## Open question

How much stamina should each treat give, and should Tokyo eat it automatically or save it for later?
