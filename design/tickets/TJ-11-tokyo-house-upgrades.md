# TJ-11 · Upgrade Tokyo's house

**Status** — Proposed

Players improve Tokyo's house using points or qualifying items earned in levels.

## Acceptance criteria

- [ ] The player can see available house upgrades and what each requires.
- [ ] Completing levels provides the points or items needed for at least one upgrade.
- [ ] Applying an upgrade updates the player's balance or inventory as specified and visibly changes Tokyo's house.
- [ ] Returning to the house later shows the upgrades already applied.

## Open question

Which upgrades should exist, and which points or earned items should pay for each one?
